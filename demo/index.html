falling-leaves

Maple leaves that sway, spin and tumble down any web page, with oak, ginkgo and birch if you want them. Works on its own or as a React component.

npm i falling-leaves

Your device is set to reduce motion, so the leaves are paused. The package does this for every visitor by default.

Try it

Use it

import { FallingLeaves } from 'falling-leaves';

// Covers the whole page
const leaves = new FallingLeaves({
  count: 40,
  wind: [0.2, 1.2],
  shapes: ['maple', 'ginkgo'],
});

leaves.update({ count: 80 }); // change it live
leaves.destroy();             // clean up
import { FallingLeaves } from 'falling-leaves/react';

export default function App() {
  return (
    <>
      <FallingLeaves
        fullScreen
        count={40}
        speed={[0.8, 1.6]}
        shapes={['oak', 'birch']}
      />
      <main>…</main>
    </>
  );
}
